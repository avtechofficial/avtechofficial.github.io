# AVTECH Contractors and Developers website

## Files
- `index.html` — website content
- `style.css` — colours, layout and responsive design
- `script.js` — mobile menu, current year and WhatsApp links
- `images/avtech-logo.png` — your supplied AVTECH logo

## Before publishing
1. Open `script.js`.
2. Replace `91XXXXXXXXXX` with your WhatsApp number in international format, without `+`, spaces or hyphens. Example format: `919876543210`.
3. In `index.html`, check the advertised rate, address, services and wording.
4. Your AVTECH logo is included in `images/avtech-logo.png`.
5. Replace the sample gallery photos with actual project photos if possible. You can upload your photos into an `images` folder and change the relevant `src` values.
6. The current sample gallery photos are hosted remotely, so they need an internet connection and may be replaced with your own images.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com/
2. Click **New repository**.
3. Name it `avtech-website` and select **Public**.
4. Create the repository, then choose **Add file → Upload files**.
5. Upload `index.html`, `style.css`, `script.js` and any image files/folders.
6. Click **Commit changes**.
7. Open repository **Settings → Pages**.
8. Under **Build and deployment**, select **Deploy from a branch**.
9. Choose branch `main` and folder `/(root)`, then click **Save**.
10. Wait a few minutes. The published address should look like `https://YOUR-USERNAME.github.io/avtech-website/`.

If the site does not appear immediately, wait a few minutes and refresh the Pages settings. GitHub's menu labels may change slightly over time.

## Important
GitHub Pages is suitable for this static website. It does not run server-side code or provide a database/admin dashboard. The contact links open WhatsApp; no messages are sent automatically.
